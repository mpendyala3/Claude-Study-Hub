CCAO Exercises · 26 graded drills

Twenty-six exercises, weighted to the blueprint

Written to the thirty CCAO-F objectives and distributed by the published domain weights, so the six exercises on output evaluation match the fact that it is 21% of the exam. Ten are graded in your browser as you type; eleven are rapid classification drills; four are prose-option decision sets; one is a lab you run in the Claude app. The checklists name the exact property each objective is written around, so a partial score tells you which property you missed.

Where the exercises sit against the blueprint Prompting 1–4 · Evaluation 5–10 · largest domain · Product and model 11–13 · Workflow 14–17 · Configuration 18–20 · Governance 21–24 · Troubleshooting 25–26
If you only have an hour: do 5, 7, 12, 21 and 25. Those five cover the decisions that recur most often across the whole exam.
Work them without the reference solution open Every exercise reveals a full worked answer, but the checklist is the teaching device: each check is a requirement the exam grades on, phrased so a failure tells you what to change. Get to a partial score first, read which checks failed, fix them, and re-check — that loop is what transfers to exam day. The browser-graded editors save your text locally, so you can come back to a half-finished answer.
The checks reward substance, not vocabulary They accept the several ways a competent answer phrases a thing, and they are strict about whether the property is present at all. A check for a missing-information rule passes on “write not stated”, “say so explicitly” or “leave it blank and flag it” — and fails on “be accurate”, because that is not a rule you could verify in an output. That distinction is the exam's, not this hub's.

Browser-graded writing

Rewrite a prompt, write Project instructions, brief a sceptical stakeholder, answer a data incident. Hit Check and each requirement passes or fails by name.

Classification drills

Fast recall for the decisions the exam repeats: validation or triage, which surface, which tier, instructions or knowledge, what actually goes in, diagnose in order.

App lab

Build a Project in the Claude app and then break it deliberately — remove the missing-information rule, add a contradictory instruction, leave a superseded document in place, and watch each failure mode arrive.
