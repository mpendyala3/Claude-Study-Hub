CCDV Exercises · 28 graded drills

Twenty-eight exercises, weighted to the blueprint

Written to the twenty-five CCDV-F skills and distributed by the published domain weights, so the nine exercises on building with the Claude API match the fact that it is 33.1% of the exam — a third of everything. Twelve are graded in your browser as you type, nine are rapid classification drills, five are prose-option decision sets, two are labs you run yourself. The checklists name the exact property each skill is written around, so a partial score tells you which property you missed rather than just that you scored badly.

Where the exercises sit against the blueprint Agentic concepts 1–4 · Building with the API 5–13 · a third of the exam · Agentic coding 14 · Modernisation 15 · Model selection 16–19 · Prompt & context 20–22 · Security 23–25 · Tools & MCP 26–28
If you only have ninety minutes: do 2, 7, 16, 19, 23 and 26. Those six cover the decisions the exam returns to most — loop termination, retry classification, which lever fits which complaint, cache ordering, capability-level defence, and what belongs in a tool definition.
Work them without the reference solution open Every exercise reveals a full worked answer, but the checklist is the teaching device: each check is a requirement the exam grades on, phrased so a failure tells you what to change. Get to a partial score first, read which checks failed, fix them, and re-check — that loop is what transfers to exam day. The browser-graded editors save your text locally, so you can come back to a half-finished answer.
The checks reward substance, not vocabulary They accept the several ways a competent answer phrases a thing, and they are strict about whether the property is present at all. A check for a termination contract passes on “cap the iterations”, “bound the loop” or “stop after N turns” — and fails on “handle errors gracefully”, because that is not a thing you could implement. Every reference answer here scores full marks against its own checklist, so if a check will not pass for you, the property really is missing.

Browser-graded writing

Write a loop termination contract, an error and retry policy, a validation design, a cost plan, an injection defence, an MCP server design. Hit Check and each requirement passes or fails by name.

Schema and request drills

Three exercises where you write actual JSON and it is parsed and inspected: an extraction schema that permits absence, a request laid out so the cache hits, and a tool definition the model can use without guessing.

Classification and decision sets

Fast recall for the choices the exam repeats: workflow or agent, retryable or fatal, which lever, which context home, which control, and which of the four ways to build an agent.
